# Cambios v1.2.2

Esta versión fue construida directamente sobre la última copia del repositorio `GobiernoInteligente/consejo_de_gobierno` entregada por el usuario.

## Agente IA

- Código embed editable desde el backend.
- Persistencia en laptop, JSON y Supabase.
- Compatibilidad con custom elements, scripts e iframes.
- Extracción dinámica: no se fija ningún `agent-id` en el código fuente.

## Control visual

- Modos columna, libre y pantalla completa.
- Posición X/Y, ancho, alto, offsets, escala y z-index.
- Marco y cabecera opcionales.
- Autoajuste del contenido.
- Presentación expandida opcional para ElevenLabs.
- Presets de posición.
